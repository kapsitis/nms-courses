# Olimpiāžu uzdevumu avoti

* [NMS olimpiāžu arhīvs](https://www.nms.lu.lv/arhivs-un-materali/uzdevumu-arhivs/olimpiazu-uzdevumu-arhivs/) - 
  agrāko gadu olimpiāžu uzdevumi pa gadiem un olimpiādēm.
* [NMS konkursu uzdevumu arhīvs](https://www.nms.lu.lv/arhivs-un-materali/uzdevumu-arhivs/konkursu-uzdevumu-arhivs/) - neklātienes konkursu (JMK, Profesora Cipariņa) uzdevumi.
* [NMS teorijas materiāli](https://www.nms.lu.lv/arhivs-un-materali/materiali/teorijas-materiali/) - 
  gatavošanās materiāli par bieži vajadzīgām tēmām.
* [NMS grāmatas](https://www.nms.lu.lv/arhivs-un-materali/gramatas/tematiskas-gramatas/) - 
  tematiskas grāmatas, tsk. 2023.g. Marutas, Agneses un Gunas 5.-9.kl. grāmata.
* [ArtOfProblemSolving sacensību uzdevumi](https://artofproblemsolving.com/community/c13_contests)
* [Problems_ru](https://problems.ru/)
